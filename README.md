# 지방자치혁신연구원 홈 리디자인 - Next.js Handoff

이 패키지는 `home.jachinews.kr` 리디자인 정적 시안을 실제 Next.js App Router 프로젝트로 옮기기 위한 컴포넌트형 구현본입니다.

## 포함 내용

- `app/page.tsx`: 홈 페이지 조립 파일
- `src/components/*`: 섹션별 React 컴포넌트
- `src/data/home.ts`: 현재 사이트 콘텐츠를 재구성한 데이터 소스
- `app/globals.css`: Tailwind CSS v4 기반 디자인 토큰과 전역 스타일
- `docs/*`: 콘텐츠 맵, 구현 메모, QA 체크리스트

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 열면 됩니다.

## 적용 방식

기존 프로젝트가 이미 있다면 전체를 새로 붙여넣기보다 아래 순서가 안전합니다.

1. `src/data/home.ts`를 먼저 검토해 실제 연락처, 과제명, 외부 링크를 확정합니다.
2. `app/globals.css`의 색상 토큰을 현재 브랜드 색과 비교합니다.
3. `src/components`를 섹션 단위로 기존 프로젝트에 복사합니다.
4. 실제 배포 전 모바일, 접근성, 링크, 한글 줄바꿈을 검수합니다.

## 디자인 방향

- 포지셔닝: 지방의회와 지자체를 위한 정책·데이터·AI 파트너
- 톤: 공공정책 연구소 + 현대적 뉴스룸 + 절제된 AI 제품 소개
- 피해야 할 것: 보라/파랑 네온 SaaS 템플릿, 의미 없는 fake dashboard, 과한 glassmorphism, stock-photo business people, 반복 카드만 있는 구성
- 우선순위: 히어로 → 신뢰 근거 → 3대 축 → AI 워크플로 → 연구 실적 → 연구 분야 → 뉴스룸 → 연구진 → 문의

## 주의

- 이미지나 인물 사진은 포함하지 않았습니다. 실제 연구진 사진을 쓸 경우 동일한 톤, 배경, 비율로 재촬영하거나 보정하는 것이 좋습니다.
- AI 기능 설명은 현재 공개 사이트 문구를 기반으로 재구성했습니다. 제품 화면이 있다면 Hero의 워크플로 카드와 AI 섹션에 실제 스크린샷을 대체 삽입할 수 있습니다.
- 수치, 연락처, 주소, 과제명은 최종 배포 전 반드시 수동 검증하세요.
